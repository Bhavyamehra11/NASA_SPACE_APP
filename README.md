# 🚀 ORBITAL COMMAND

### Design. Explore. Launch.

ORBITAL COMMAND is an interactive space mission design game created for the NASA Space Apps Challenge.

The game allows players to experience the challenges of planning a space mission by designing their own spacecraft, managing resources and attempting to complete missions to different destinations.

## 🌌 About the Game

Players take on the role of a space mission designer. They must choose a destination, build a spacecraft and select a suitable launch vehicle while working within a limited budget.

Every decision affects the mission's chances of success.

## 🪐 Mission Destinations

- Moon Exploration
- Mars Expedition
- Deep Space Mission

## 🛠️ Spacecraft Design

Players can select different spacecraft systems:

- Power systems
- Communication systems
- Propulsion systems
- Flight computers
- Scientific instruments

## 🎯 Game Objectives

Players must balance:

- Mission budget
- Spacecraft mass
- Power generation and consumption
- Scientific value
- Equipment reliability
- Rocket payload capacity

## 🚀 Mission Simulation

After designing their spacecraft, players select a launch vehicle and run a mission simulation.

The simulation includes mission events, possible failures and a final performance score.

## 💻 Technologies Used

- HTML – Structure of the game
- CSS – Styling and visual design
- JavaScript – Game logic, calculations and simulation

## ▶️ How to Play

1. Open the game in a web browser.
2. Select a mission destination.
3. Design your spacecraft.
4. Select scientific instruments.
5. Choose a compatible launch vehicle.
6. Launch your mission.
7. Review your mission results.

## 🎓 Educational Purpose

ORBITAL COMMAND aims to make space exploration and mission planning easier to understand through interactive learning.

It demonstrates how engineers must balance different technical requirements and make decisions when designing a space mission.
